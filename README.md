# El espectro invisible · versión narrativa

Infografía web interactiva para Vercel.

## Ejecutar
```bash
npm install
npm run dev
```

## Publicar
Sube el contenido de esta carpeta al repositorio conectado con Vercel. Vercel ejecutará `npm run build` y publicará `dist`.

## Nota científica
La relación entre tubos de vacío y auroras se presenta como analogía histórica con límites. La Tierra no es literalmente un tubo de vacío y las auroras no son radiactividad ni rayos X.
